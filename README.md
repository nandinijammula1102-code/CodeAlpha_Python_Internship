# CodeAlpha Python Programming Internship

## 📌 Project Overview

This repository contains my Python programming projects completed as part of the **CodeAlpha Python Programming Internship**.

The projects demonstrate fundamental Python concepts such as:

* Variables and data types
* Lists and dictionaries
* Conditional statements
* Loops
* Functions
* User input and output
* Basic file handling
* Random module

## 📂 Projects

### 1. Hangman Game

A simple text-based Hangman game where the player guesses a randomly selected word one letter at a time.

**Features:**

* Uses 5 predefined words
* Randomly selects a word
* Allows the player to guess one letter at a time
* Maximum of 6 incorrect guesses
* Displays the progress of the guessed word
* Shows the correct word when the player loses

**Python Concepts Used:**

* `random`
* Lists
* Strings
* `while` loop
* `if-else`
* User input/output

**File:**

```text
task1_hangman.py
```

---

### 2. Stock Portfolio Tracker

A simple stock portfolio tracker that calculates the total investment value based on manually defined stock prices.

**Features:**

* Displays available stocks and prices
* Allows users to enter stock symbols
* Allows users to enter quantities
* Calculates the investment value for each stock
* Calculates the total investment value
* Saves the portfolio summary to a `.txt` file

**Python Concepts Used:**

* Dictionaries
* User input/output
* Basic arithmetic
* Loops
* Conditional statements
* File handling

**Files:**

```text
task2_stock_portfolio.py
portfolio.txt
```

---

### 4. Basic Chatbot

A simple rule-based chatbot that responds to predefined user messages.

**Features:**

* Responds to greetings such as `hello` and `hi`
* Responds to `how are you`
* Provides its name
* Provides basic help
* Ends the conversation when the user types `bye`
* Handles unknown messages

**Python Concepts Used:**

* Functions
* `if-elif-else`
* `while` loop
* User input/output
* Strings

**File:**

```text
task4_chatbot.py
```
